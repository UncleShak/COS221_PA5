02 Liquid Glass UI
Frosted Clear · iOS Blur · One UI

Materials

Three Glass Styles

Frosted (pricing cards), Clear (iOS-style transparent rows), and Heavy Blur (One UI navbars and modals) — all adapted to the warm Alpine palette.

Style A — Frosted
Frosted Glass

Moderate blur, warm white tint. Primary use: pricing cards (like the reference pricing layout), package cards, sidebars.

backdrop-filter: blur(22px)
background: rgba(255,248,244, 0.45)
Standard Plan
R 299/mo
Style B — Clear · iOS
Clear Glass

High transparency, subtle blur. Background shows fully through. Used for secondary rows, hover overlays, floating chips.

backdrop-filter: blur(12px)
background: rgba(255,255,255, 0.14)
Style C — Blur · One UI
Heavy Blur

Highly opaque blur base — used for navbars, modals, and any panel requiring maximum text legibility over any background.

backdrop-filter: blur(40px)
background: rgba(255,255,255, 0.82)
